# Omo Forest Reserve Health Access Project

## The question
How far are settlements surrounding Omo Forest Reserve from the nearest health facility?

## The study area
Communities surrounding Omo Forest Reserve, Ijebu East LGA, Ogun State, Nigeria.

## Datasets used
- Forest reserve boundary — Omo Strict Natural Reserve (Protected Planet/WDPA)
- LGA boundary — GRID3 Operational LGA Boundaries
- Settlement extents — GRID3 Nigeria Settlement Extents v4.1
- Health facilities — GRID3 Health Care Facilities v2.0
- Roads — OpenStreetMap (Geofabrik Nigeria extract)

See data-note.md for full details on each dataset, including source links, format, and status.

This folder contains QGIS screenshots as evidence that each dataset has been downloaded and opened successfully.
