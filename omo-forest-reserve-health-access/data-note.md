Data Note
Settlement Extents

Source: GRID3 (via Columbia Academic Commons)

Source link: https://academiccommons.columbia.edu

Dataset: GRID3 Nigeria Settlement Extents

Study area: Communities surrounding Omo Forest Reserve, Ijebu East LGA, Ogun State, Nigeria

Data type: Vector

Purpose: The settlement extents will be used to identify populated areas surrounding Omo Forest Reserve and measure their distance from the nearest health facility, to assess healthcare access.

Time period: Most recent available version (dataset updated periodically by GRID3)

Geometry type: Polygon

Number of features: To be confirmed after the data is opened in QGIS and clipped to the study area

Key information: The important information in the dataset includes settlement boundary shape, settlement type/classification (if attributed), and coordinate reference system.

Missing values or gaps: Any missing attributes or unclassified settlement polygons will be checked after the data is opened in QGIS.

Software used: QGIS

Data status: Downloaded from Columbia Academic Commons and opened in QGIS for inspection.
